PrizeVault proof of funds

Reads the tournament record straight from a Stellar RPC node (simulateTransaction of status), so anyone with this link can verify the prize pool is escrowed before they register.

Verify it yourself from a terminal: prizevault proof-of-funds --id <id> --contract-id <contract> --rpc-url <rpc>. The page performs no transactions and needs no wallet; it only simulates a read.
